## How it plays

Clara explores **1850** with an oil lamp; Silas explores **2450** with a flashlight. Their different environments provide different information and ways to shape the light path. Align mirrors, remove physical obstructions and use the other era's illumination to reveal clues and open routes.

- **Puzzle 1:** use sound cues and cooperative illumination to retrieve the first mirror and create a moonlit waiting place.
- **Puzzle 2:** establish temporal overlap, connect paired reflectors and redirect light to the stair catch.
- **Puzzle 3:** reorganize the light route while managing darkness, supplies and toxic fog; open the low cabinet and guide both characters to their exits.

The native application supports **one-person review of both characters**. Optional localhost browser role views share the same running native host. They are not independent game clients; this release does not provide internet multiplayer or built-in voice transmission. The Mac has one focused keyboard/mouse window at a time.

## Essential native controls

| Action | Key |
| --- | --- |
| Move Clara / Silas | WASD / IJKL |
| Select interacting character | Tab |
| Interact / grip / release | E |
| Aim flashlight | Mouse |
| Turn mirror / tilt mirror | Q, R / Z, V |
| Fine mirror adjustment | Hold Shift |
| Oil / battery refill | B or upper-left supply icon |
| Records / inspect | N / X |
| Chapter menu / P3 retry | F10 / F5 |

Chapter checkpoints supply prerequisite discoveries. P3 retry restores an in-session safe pause, or the alarm start if no safe pause exists. Physical world state does not resume after quitting.
